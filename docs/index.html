02 / BEHIND THE SOUND

Not a recording.
A set of possibilities.

A strike is brief. Its resonances tell the rest of the story. Each tube in this study excites five independently decaying modes, letting a small collection of parameters produce an evolving soundscape.

01 — EXCITATION

Chance becomes rhythm.

The wind control changes the rate and strength of irregular strikes. Gusts briefly raise that activity. This prototype uses a stochastic event scheduler, not a mechanical collision simulation.

02 — RESONANCE

Pitch is only the beginning.

The five frequency sets come directly from tube_modes. Their non-integer relationships create an inharmonic timbre. The first tube retains the unusual 64.6 Hz mode exactly as written in the source.

03 — DECAY

Let the material speak.

Each mode fades at its own rate. The resonance control scales these decay times without shifting pitch. Upper modes can disappear sooner, changing the spectral balance as the sound dies away.

04 / PROJECT & RESEARCH

From analysis
to an instrument.

The original MATLAB study analyses the opening two seconds of wood.wav with a 4096-point spectrogram and 90% overlap, then sketches a wind-driven synthesis pipeline. This playable interpretation brings its published modal parameter set into the browser.

Implementation notes & limitations +

The repository does not include wood.wav or the wind, energy, clapper and synthesis helper functions. Its final synthesis call is commented out. This demo is therefore not an exact reproduction of the original renderer.

Audio here is a sum of damped sinusoidal modes with a 2 ms onset, source gains and stereo placement. The source pole radii are converted to decay constants using a nominal 44.1 kHz reference rate because the recording’s sample rate is unavailable. No reverb is added.

For amplitude decay, T60 = −3 / (Fs log10 r). The source’s example uses −6 in the radius exponent, which reaches −120 dB amplitude at the stated time. Its peak-analysis gain calculation also returns the parabola’s frequency offset, not its peak amplitude. This demo uses the separately hard-coded gains, not that estimator.

The animation illustrates motion and strikes; tube geometry is not calibrated to the modal frequencies. The stochastic scheduler and user controls are additions for this prototype.
